待核对模式恢复的 8 个查询（3 个有答案、5 个协议无答案）全部标注 `review_required`。
通过严格启发式的另外 16 个查询也只是 `candidates`，不是“答案已验证”。这些状态是
查询级候选集状态，不是每篇资料都支持答案。沿用的 `no_answer_false_positive_count`
是旧检索协议指标，不是生成幻觉率；本次没有答案生成器或语义支持性裁判。

表示诊断仍使用人工模型响应：默认文本完整限定语 5/8 → 8/8，来源 ID 0/8 → 8/8，
关联 ID 0/2 → 2/2。七张卡的八个来源引用均有实际别名绑定，另用存储单测覆盖非连续
编号、原始请求元数据变动、持久化和旧卡缺映射。embedding 文本继续不加入来源 ID，
因为身份信息应随命中结果传递，不是向量语义文本的内容。

报告同时保留相同字符预算统计；更长的完整输出不代表同预算表现更好。
来源绑定不是 entailment；输入片段选择 manifest 不是逐主张支持证据，更不是来源授权。

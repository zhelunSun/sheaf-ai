## 1. 产品定位

**Sheaf 让你的 Agent 用上你挑选的资料和形成的判断，并帮助你决定哪些内容值得亲自读。**

长期定位是 **Agent 时代的个人知识基础设施**。上述功能概括是产品方向；已实现的
基础与尚待补齐的体验见下文，不将整句视为当前版本全部交付的承诺。

产品要让日常收藏在需要时参与实际工作。用户把资料留下，Sheaf 负责保存、整理和
查找，Agent 在研究、选型、写作等任务中使用相关内容，并让用户能回到原文核查。
用户不需要先填写收藏理由、给材料评分、维护立场标签，或花时间教系统理解自己的
知识品味。**零额外反馈也应有用；轻量反馈只能增益，不能成为使用前提。**

收藏是一条“可能有用”的线索，不证明资料正确，也不代表用户认同作者观点。
阅读、引用、收藏数量和重复出现都不能被自动解释为认可。系统应区分来源说法、
Agent 推导与用户主动表达的判断；未表达的判断保持未知。

“个人知识基础设施”说明资料可以长期保留、由用户控制，并供不同 Agent 使用。
它本身不是已经证实的市场空位。当前要证明的是：在现有 Agent 和资料工具之外，
Sheaf 能否让用户更少重找资料、更少重复说明、更容易核查，并愿意持续使用。
接口可调用、卡片可生成和工程测试通过，都不能替代这一证据。

## 2. 默认使用方式

产品主线是：**收藏 → 自动筛选 → 原文可查 → Agent 任务复用**。
这是开发与验收的体验目标；其中自动筛选和持续复用尚需补齐与实测，不能把这条
链路整体宣传为已经验证的能力。

1. **随手收藏**：继续使用链接、文本和现有扩展入口。不强制用户解释为何收藏，
   也不要求先建立主题、项目或分类体系。
2. **按当前任务自动筛选**：从已存资料中找相关内容，必要时提供少量摘要或阅读
   建议。选择应能说明依据，保留不确定性；筛选结果不意味着静默删除原始资料。
3. **随时回到原文**：展示来源和有关段落，让用户能区分原文与综合结果。
   知识卡片是按需生成的派生视图，不是每份资料进入检索与使用的必经步骤。
4. **在原来的 Agent 中使用**：用户继续通过现有 Agent 发起任务，获得带来源的
   输出。收藏、整理与复用应自然衔接，而不是新增一套必须学习的工作台。

反馈应来自自然使用：用户主动说“这条过时了”“这次别用这个来源”时，系统提供
明确、可纠正的处理方式。将反馈用于后续行为是计划中的能力，不能因保存了一条
批注就声称已经学会偏好。当前任务的限制也不能默认升级为长期偏好。

原文、来源信息和用户主动留下的文字应保留；派生摘要与卡片可重新生成，不覆盖
用户原话。首轮可以使用现有 Agent 输出、链接和 note 完成核查，不以新增侧栏、
完整阅读器或聊天界面为前置。只有真实使用反复被界面阻塞时，才补最小视图。

## 3. 现有能力与产品缺口

下表区分已存在的工程基础与待完成的用户体验。详细功能状态和验收见
[PRODUCT-FEATURES.md](PRODUCT-FEATURES.md)。

| 用户动作或结果 | 现有基础 | 当前边界与下一步 |
|---|---|---|
| 收藏并找回资料 | 链接与文本采集、本地存储、Chrome 扩展、关键词与语义检索入口 | 保留并实测常用来源；桌面入口可用不证明手机或微信收藏低摩擦 |
| 当前任务中少找资料 | 检索、分类、摘要、重要性和列表等组件 | 尚未验证零反馈条件下的筛选与复用体验；先接通一个真实任务 |
| 核查 Agent 使用的依据 | 来源映射、原文段落选择、卡片详情与部分消费路径 | 接口存在不保证 Agent 正确调用和展示；需要验收原文与结论之间的实际跳转 |
| 按需综合多份资料 | 结晶、严格输出契约、保守去重、卡片批保存 | 尚未证明卡片普遍优于原文；允许直接用原文，展示失败与局限 |
| 自然纠错后少重复解释 | 当前条目的纠错与 note；受约束的版本和历史机制 | 纠错记录不等于未来行为会改变；普通卡也不会自动接入治理账本 |
| 让不同 Agent 使用同一资料 | CLI、MCP、HTTP 和部署说明 | 继续维护共用能力与兼容性；跨 Agent 的连续使用价值仍待真实验证 |

## 4. 当前推进顺序

近期重点是用现有能力交付并检验最小产品循环，同时修复影响这条循环的质量问题。
2026-09-28 补充：优先修补采集阶段结果完整性、条目纠正后的派生状态和最小恢复路径；
这是可靠复用的基础，不等于偏好学习已接通或新功能已交付。具体依赖见当前推进计划。
首批候选场景是重度 Agent 用户的 AI 技术选型或持续专题研究；这是默认验证候选，
尚未固定为唯一人群、正式用户名单或试用日程。

| 工作 | 当前安排 | 进入下一步的依据 |
|---|---|---|
| 零反馈也有用的真实复用 | 当前产品重点；先用已有资料与入口完成真实任务 | 用户无需额外教学就找回并用上资料，核查与整理的总负担有可见下降 |
| 安装、采集、保存和输出可靠性 | 持续维护，修复实际阻塞 | 适用的契约、隐私、安全、兼容和发布检查通过 |
| 原文、摘要与卡片选择 | 支撑产品的小范围比较 | 在相同任务和资料下确定何时值得生成卡片，避免强制结晶 |
| 自然反馈与后续行为 | 按实际重复错误补最小路径 | 能显示纠错结果及适用范围，不要求用户提前标注资料 |
| 更复杂的检索或自动演化策略 | 保留实现与回归，新增工作按真实失败排队 | 简单方案持续不足，且新方法在相关任务上有收益证据 |
| 分发与商业验证 | 跟随持续使用中的实际需求 | 有重复使用、可接受的维护负担与愿付成本证据 |

真人使用不以完成全部算法留出集、自动演化策略或全部新功能为前置。对照应包括
用户现有工作流、相同资料和同等个人指令；零反馈阶段不额外给 Sheaf 人工标注优势。
若观察纠错复用，两侧都应得到相同纠正信息。模拟用户和合成集用于发现失败，不能
替代真人选择是否继续使用。

这一顺序不放宽现有安全、数据保存、兼容与发布门禁，也不将未验收的自动行为默认
开启。对产品循环没有已知影响的研究实验不再阻塞试用；会丢失资料、错误覆盖用户
文字或暴露数据的问题仍必须先解决。具体范围与停止条件见
[NEXT-PHASE-PLAN.md](NEXT-PHASE-PLAN.md)。

## 5. 基础设施与商业远景

本地优先、开放格式、可导出与跨 Agent 接入继续作为基础。知识不仅可以是事实，
也可以包含方法、经验和操作说明；Skill 同样可以承载这些内容。Sheaf 是否需要独立
存在，取决于持续摄入、查找、按需组合和更新这些内容能否比维护现有文件或 Skill
更省事，不能仅用内容类型划出竞争边界。

知识包分享、经验证知识的授权与交易、Web3 和链上知识主权保留为远景。启动这些
方向需要真实的供需、可说明的验证条件、权利与授权边界，而不只是已有打包格式。
链上记录不能单独证明内容真实、创作权利或用户付费意愿；当前不建设交易市场、
代币或版税体系。旧的 Matrix 自动扩库、复杂协作和泛化对话记忆也不自动恢复为
产品主线。

## 6. 工程能力如何支撑产品

检索、结晶和增量知识演化继续作为支撑能力。它们描述系统职责，不代表三项原创
算法，也不构成用户必须经历的三步流程。采集适配、来源质量、可靠保存和 Agent
接口同样是产品必要部分；任务价值不按算法创新数量排序。

```text
用户旅程：收藏 → 自动筛选 → 原文核查 → Agent 任务复用
        ↓
支撑能力：采集、检索、按需结晶、更新与历史、Agent 接口
        ↓
领域记录：Entry、KnowledgeCard、EvidenceEvent、CardVersion
        ↓
基础设施：抓取器、本地存储、模型与 embedding 适配器
        ↓
质量保障：契约测试、模拟用户、针对性评测、构建与安装门禁
```

每项新增工作需说明服务哪个用户动作、目前失败在哪里、最简单可行方案和如何
验收。CLI、MCP 和 HTTP 共享业务能力；来源解析、状态转移和历史属于领域边界，
本地文件、模型提供商与网页适配属于可替换基础设施。已有格式与数据不因定位调整
自动迁移，公共契约改动继续执行兼容与迁移要求。

架构和声明边界见 [ARCHITECTURE-AND-EVALUATION.md](ARCHITECTURE-AND-EVALUATION.md)。
研究问题与实验次序见
[REPRESENTATION-AND-RESEARCH-AGENDA.md](REPRESENTATION-AND-RESEARCH-AGENDA.md)，
其中的研究门槛用于约束相应方法声明，不作为整个产品开发的统一前置。

## 7. 保留的技术与实验快照（截至 2026-09-22）

以下保留既有实现、约束和负结果，避免定位调整被误读为技术问题已经解决。
这些是此前工程与实验记录，本次没有重跑，也没有新增效果结论。

| 路径 | 回答的问题 | 当前实现 | 主要缺口 |
|---|---|---|---|
| 检索 | 用户问问题时，应该取回哪些已收藏证据？ | BM25、直接 Entry 语义索引、query-level 拒答、作用域先行过滤、Unicode/CJK 实体处理和冻结消融 | 真实 embedding、跨语言/改写误拒、否定证据与证据不足的区分 |
| 结晶 | 多份来源共同支持什么可复用结论？ | 模型抽取、严格 schema、可解析来源约束、带原文偏移的 passage selection，以及条件/测量范围/缺失语义的真实模型开发回归 | 独立长来源留出、同预算收益、逐事实语义支持、重复控制和用户价值 |
| 增量知识演化 | 新证据到来后，旧知识应该怎样改变？ | 显式状态转移、schema 4 原子 batch、可信来源登记、旧账本重放，以及绑定执行计划的 SPLIT/NOOP | 自动转移策略、独立性奖励校准、跨文件恢复和留出评测 |

三条路径成熟度并不相同：增量演化的单动作确定性执行器已有较扎实的机制证据；
检索的真实 Entry 语义链路和冻结评测已经接通，但 local-LSA 混合方案在不同合成集
上表现不同，尚不能证明普遍优于关键词；结晶的实际价值仍依赖任务与模型质量。

增量演化当前使用 `evidence-rule-v3`。non-duplicate group 只按同一 `source_key`、可信
的版本化全文 SHA-256 digest、或已持久化的 `exact` / `near_duplicate` 关系形成；普通
自声明 provenance 只用于审计，绝不能推翻这些去重关系。group 不等于已经验证的独立
确认：`independent_source_count` 仍保守为 `1`，corroboration bonus 关闭，直到新的评分
版本完成独立评测。可信 provenance registry 已负责授权而非直接改分：attestation 精确
绑定 Entry、origin 和全文 digest；缺失、冲突、损坏或撤销时降为 `U`。hash chain 只做
完整性检查，不是身份认证。历史评分按原算法重放。

SPLIT/NOOP decision trace 已接入 production evidence-ledger adapter：UPDATE + CREATE、
head CAS 和 receipt 通过一次领域账本替换提交；执行计划 hash 绑定操作、证据、目标版本
和策略版本。decision ledger 与 evidence ledger 仍是两个文件，因此准确表述是“领域内
原子、跨账本可恢复”，不是跨文件事务。

幂等键、请求哈希、文件锁、原子写入和历史重放属于可靠性机制。它们不单独构成
算法创新，但让三条路径可以安全重试、审计和解释。

最新工程阶段见[生产链路加固](HARDENING-2026-09-22.md)：完整输出检查、跨接口诊断、
保守去重和卡片文件内原子批保存已接通，模拟用户执行入口已加固。该轮没有新的
模型效果分数；实际生产结晶路径的小型新样本验收仍未由本次文档更新完成。

[长来源实验](LONG-SOURCE-EXPERIMENT-2026-09-05.md)包含 8 组 24 题的真实比较和独立
智能体语义审核，累计 132 次调用、253378 tokens，保留截断失败及实际文本预算修订。
事实抽取仅 3/8 组通过契约，任务范围过滤未显示可靠收益，不能据此扩大 schema 或
迁移生产默认。前轮已饱和的
[Flash 十二题实验](DEEPSEEK-V4-FLASH-EXPERIMENT-2026-09-05.md)继续作为历史回归。
治理状态读取见[版本卡读取与方法选择实验准备](METHOD-SELECTION-PHASE-2026-09-04.md)。
[2026-09-04 修复记录](FIX-ROUND-2026-09-04.md)中的完整主张、来源映射与检索不确定性
已接通部分消费路径；review 仅恢复待检查资料，不代表自动判断可答。

第一份检索资产已经冻结为 22 条 Entry、36 个 query，manifest 锁定三份 fixture 的
hash，并在产生 ranking 后才加载 qrels。经典 local-LSA 基线经 dev 选择
`linear-0.25 @ 0.4`，留出集为 Recall@5 `0.9375`、MRR `1.0`、nDCG@5 `0.9498`、
no-answer FPR `1.0`；它没有优于 keyword，也没有解决 abstention。query-support-v3 在
已看过标签的 post-hoc 回归上把 FPR 降到 `0.0` 并保持 Recall@5 `1.0`，但不是新盲测。
真实 embedding 因缺少凭据尚未运行。相关度 gate 是 backend/version-specific 实验
信号，不能解释为概率或通用阈值。

2026-09-04 的新合成集合已经完成固定参数实验：28 条资料、24 条问题。当轮拒答配置
误拒有答案问题 3/16，协议无答案问题仍误放 3/8；旧集 FPR=0 因此不能解释为普遍有效。
而且返回明确否定某能力的资料可能支持正确答案，检索 FPR 不能称为幻觉率。详见
[本轮实验记录](EXPERIMENT-ROUND-2026-09-04.md)。

生产表示通道的字段传输与最小消费边界已经接通；长来源实验进一步暴露抽取超量、
引文不匹配、类型混用和最终决定/理由矛盾。实验是小型合成诊断，不是人类金标准，
也不是完整生产结晶效果。9 月 22 日已经完成一轮输出契约加固，新样本语义验收仍待
开展；这项验收约束结晶效果声明，不要求用户先等完整增量大试验。跨文件恢复仍是
平台风险，应在会触及该风险的功能范围内处理。

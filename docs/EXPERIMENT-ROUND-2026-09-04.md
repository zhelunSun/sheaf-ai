## 2. 表示通道：单独测信息传递，不冒充模型能力

六类人工响应覆盖条件、范围、时间版本、否定例外、多主张证据配对、关系类型。
走真实 parser，再比较卡片存储表示、默认文本/JSON、详细文本、卡片 embedding 输入。
原生输出与相同字符预算分别报告；未知结构字段探针与当前支持字段分开。

这些是故意设计的传输夹具，不是自然分布上的模型输出；不能得出模型抽取成功率、
Agent 理解率或结构化表示比普通文本更好的结论。

七张卡中的 8 处完整限定语都通过 parser 保留；默认文本视图只显示其中 5 处，而原生
默认 JSON、详细文本和 embedding 文本都保留 8 处。缺失的三处分别涉及句尾条件、
版本日期和否定例外。一个范围限定语虽在 claim 末尾被裁掉，却因 evidence 有副本
仍可见，说明不同字段之间不能混计“原字段保留”与“最终文本可见”。

完整来源 ID 和关联 ID 仅在存储 JSON/详细文本中可见；默认视图和 embedding 文本
仍有 `[Source N]` 标记，但没有标记到真实来源 ID 的映射。此诊断只测这些具体序列化
函数，不代表所有外层接口都缺少补充映射。6 个未知结构字段未进入 parser 产物，另列
为兼容性探针，不算模型错误。这些结果没有证明需要完整知识图谱，却具体说明了应先
修好或显式定义哪些传输契约。

## 3. 本轮研究决策

不把三条核心路径称为三项原创算法；不把可靠执行器等同完整知识管理产品。
接下来的候选方法问题是：在同样资料、模型和预算下，保留适用条件与可定位证据的
知识表示，是否减少任务中的错误使用，并以可接受的成本维护变化？

这仍是假设。对照必须包含条件完整的普通文本卡，不能通过给结构组更多信息来获得
“结构优势”。完整研究范围与 R0–R4 顺序见
[研究计划](REPRESENTATION-AND-RESEARCH-AGENDA.md)。

四个一手来源的阅读账本有 0 errors / 0 warnings，但其中三个只读了摘要。
PROV-DM 引用段落已正文核对；H1 仍未验证。这既不是完整新颖性审查，也不是论文就绪结论。

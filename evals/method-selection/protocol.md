# 方法选择实验 v1：先验证表示是否帮助使用知识

状态：内部合成开发集和可执行实验协议，不是独立留出，不是产品效果结论。
创建基线 ef2a272；本阶段同时修复治理状态输出，但不调检索参数。

## 问题与比较组

任务是依据给定来源，为一个有明确约束的需求选择方法，或说明不能选择。
六个来源包、十二个问题覆盖适用条件、版本变化、明确否定、证据不足和冲突。
所有名称和能力均为人为设定，不是对真实产品的事实描述。样本作者知道规则与答案；
这一版全部是开发诊断样本。以后需要新增来源包/主题留出，不能拿本集证明泛化。

比较原文块、条件完整的普通文本卡、最小结构卡。后两组来自同一次中立抽取，包含
完全相同的主张、条件、例外和引用；普通文本用生产 KnowledgeCard/renderer 输出，
结构组用实验 JSON 输出。抽取器要求两组共有的信息，不给结构组额外资料或答案。
这先隔离表示形式的影响，不等同生产结晶提示词或所有知识卡系统之间的比较。

原文与卡片比较包含抽取/压缩的影响；文本与结构卡比较更接近格式影响。一个抽取
错误会共同影响两种卡，不把这些错误隐去。原文组不承担抽取费用；卡片组若独立部署，
各自需承担完整的每来源包构建费用，不能因实验共享一次抽取就把构建成本除以二。

## 先固定边界，再运行

- 模型运行前必须显式指定同一个模型 ID；所有请求 temperature=0、固定输出上限。
- 当前预检只限制每组相同的 context 字符上限（默认 6000），不冒充 token 预算。
  不截断句子或 JSON；某组超限则该组该任务标记 preparation_failed，保留在评价分母。
  卡片抽取失败不阻止原文组运行；三个组始终使用相同十二题分母，不只比较成功样本。
  正式同 token 预算实验仍需固定模型 tokenizer、计数规则与预算，另立协议版本。
- 原文、抽取和回答请求都完整导出；无网络默认、无隐式模型调用。真实模型执行器
  回填请求 hash、模型 ID、原始文本、结束原因、usage 和耗时后，再导入评分。
- 回填的身份/usage 是执行器记录，不是独立认证。缺失费用记 unknown，不记为零。
  模型标识不一致、未知/重复/缺失响应、请求内容 hash 不符均拒绝评分。
- 持久化请求计划包含输入/协议/runner/renderer 源码指纹；回答前与评分前核对。
  已生成文件只允许独占创建，不覆盖、不偷偷重试；失败或截断响应计失败。
- inputs.json 无答案、类别、split 标签；gold.json 仅评分/预检检查读取。准备抽取与
  准备回答不打开或 hash gold。所有回答响应完整收齐后才读取 gold。

## 指标与判断

逐题报告：选择/弃答及方法是否正确、证据状态是否正确、引用是否能对应唯一原文、
必需来源是否覆盖、准备/模型/格式失败。否定证据可以支持正确弃答，不将“非空结果”
计作幻觉。引用可定位不是主张被蕴含；理由文本的语义支持仍需独立人工或经审核裁判。

这个十二题开发试验不设置“达到某准确率即可证明创新”的门槛。启动新的正式留出前，
建议预先固定：结构组相对条件完整文本的错误适用改善、置信区间、构建/查询成本上限，
并安排多次运行。不得见本轮分数后回填验收线。若普通文本已足够，优先保留简单表示。

当前不做：检索优化、自动动作选择、真实用户/付费验证、论文新颖性宣称。
本阶段退出条件是治理状态消费契约可测、三个表示组可接真实响应、标签隔离与失败分母
有测试；不是完成 R2 的真实模型效果验证。
